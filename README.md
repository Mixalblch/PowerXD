# PowerXD

Портативное приложение для Windows 11, которое переключает схемы электропитания
(«Панель управления → Электропитание») прямо из системного трея — без прав
администратора и без UAC.

## Возможности

- 🖥️ Работает из системного трея (иконка — кружок с символом питания).
- ⚡ При клике по иконке открывается кастомное окно в стиле
  [impeccable.style](https://impeccable.style/) / [threeui](https://github.com/MengTo/threeui):
  тёмное «стекло», скругления, анимация появления.
- 🔌 Показывает все схемы питания как они есть в Панели управления
  (считывает через WMI `Win32_PowerPlan`, переключение через `powercfg /setactive`).
- ✅ Активная схема подсвечена и отмечена галочкой.
- 🟢🔵🟠 Текущий режим отображается в подсказке иконки и цветной точкой на ней.
- 🚀 Автозапуск через реестр `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`
  (тумблер в окне).
- 🌐 Локализация RU/EN (переключается в окне).
- 🧩 Один портативный EXE, запуск сразу в трей.

## Сборка

Нужен .NET 8 SDK (можно поставить локально без прав администратора):

```powershell
# 1. Установить SDK локально (если нет системного)
Invoke-WebRequest https://aka.ms/dotnet/8.0/dotnet-sdk-win-x64.zip -OutFile $env:TEMP\sdk.zip
Expand-Archive $env:TEMP\sdk.zip -DestinationPath "$env:USERPROFILE\.dotnet" -Force

# 2. Собрать
.\build.ps1
```

Результат:

| Папка | Описание |
|-------|----------|
| `publish\portable\PowerXD.exe` | Один EXE, требует установленный .NET 8 Desktop Runtime (маленький) |
| `publish\self-contained\PowerXD.exe` | Полностью автономный EXE (работает без установленного .NET) |

## Использование

1. Запустите `PowerXD.exe` — приложение появится в трее (при первом запуске окно
   откроется один раз).
2. Левый клик по иконке — открыть/закрыть окно выбора режима.
3. Выберите схему — переключение произойдёт мгновенно, без прав администратора.
4. Тумблер «Запускать вместе с Windows» включает/выключает автозапуск.
5. «Выход» — полностью закрыть приложение.

## Примечания

- Стандартные схемы (Сбалансированный, Высокая производительность, Экономия
  энергии) переключаются без прав администратора.
- Если в системе есть сторонние/скрытые схемы — они тоже будут показаны.
- Настройки хранятся в `%APPDATA%\PowerXD\settings.json`.
- Приложение однократное: повторный запуск просто покажет сообщение и завершится.
